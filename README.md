# Wetterauskunft-und-Outfitberater
Eine Webseite die basierend auf  den gegebenen Standort das Wetter anzeigt und auch Empfehlungen bezüglich passender Klamotten gibt

Für die Nutzung benötigt man einen OpenWeatherMap-Key, welchen man in die script.js eintragen muss.

Zudem wurde auch zur besseren Visualisierung auch ein Dark Mode eingefügt.
